# Receita Divertida

Web app em React + Vite para receitas, planejamento alimentar e acessibilidade.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no navegador.

## Build

```bash
npm run build
```

## Funcionalidades

- Landing page responsiva
- Receitas com busca e filtros
- Favoritos com localStorage
- Página de detalhes da receita
- Modo cozinha com passo a passo
- Narração usando SpeechSynthesis
- Planejamento semanal
- Lembretes configuráveis
- Modo escuro
- Modo calmante
- Três níveis de fonte
